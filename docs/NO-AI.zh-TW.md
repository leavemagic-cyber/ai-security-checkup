# 不用 AI 的安全更新懶人包

[回首頁](../README.zh-TW.md) · [English](NO-AI.md)

**用 Windows、想下載後雙擊檢查與協助更新？看[Windows 小幫手（預覽版）](WINDOWS.zh-TW.md)。以下是不下載工具的做法。**

**不用註冊 AI、不用下載這個 Repo、不用打指令或看版本號。先點你平常會做的事。**

- [我用 Chrome 上網](#我用-chrome-上網)
- [我用 Firefox 上網](#我用-firefox-上網)
- [我有安裝 AI 工具，或使用整合多家 AI 的服務](#我有安裝-ai-工具)
- [我有自己的 WordPress、部落格或商店網站](#我有自己的網站)
- [我不知道自己用到哪些](#我不知道自己用到哪些)

這是一份點選分類的操作指南，**不會掃描你的裝置，也不會按一下就自動修好全部漏洞**。只做你有用到的項目。重啟前先存好文件、表單及其他工作。

## 我用 Chrome 上網

在你平常使用的 **Chrome 電腦版**操作：

1. 點右上角 **⋮ → 說明 → 關於 Google Chrome**。
2. 等它檢查、下載更新。需要重啟時，存好工作再按 **重新啟動**。
3. 重新開啟後，再到同一個畫面，確認顯示已是最新版本，且沒有「更新失敗」或仍待重啟。

遇到問題可直接開 [Google 官方更新說明](https://support.google.com/chrome/answer/95414?hl=zh-Hant)，手機使用者在該頁選 Android 或 iPhone／iPad。Linux、公司管理或已不受支援的裝置，依官方對應方式處理；不要為了更新解除公司管理或安全保護。

**這樣完成的是瀏覽器更新。** eMudhra 事件還涉及另行配送的憑證封鎖清單，這份指南不會驗證你實際收到哪份清單，也不能據此保證其他 App 都已修好。若出現「連線不安全」或憑證警告，不要繼續輸入密碼，也不要按略過。

## 我用 Firefox 上網

在你平常使用的 **Firefox 電腦版**操作：

1. Windows：點右上角 **☰ → 說明 → 關於 Firefox**。Mac：點螢幕上方 **Firefox → 關於 Firefox**。
2. 等它檢查、下載更新。存好工作後，按 **重新啟動 Firefox 以套用更新**（名稱可能略有不同）。
3. 重新開啟後，再到「關於 Firefox」確認沒有待安裝或待重啟的更新。顯示更新失敗時，先照 [Mozilla 官方說明](https://support.mozilla.org/zh-TW/kb/update-firefox-latest-release)處理。

從 Microsoft Store 安裝的 Firefox，請用原商店的更新功能；Linux 發行版提供的版本，沿用原本的軟體更新方式。不要另裝來源不同的副本當作更新完成。

Mozilla 說明標準設定的 Firefox 已自動收到 eMudhra 封鎖；部分自訂設定使用者則需要相關更新。這份指南沒有檢測你的封鎖狀態。遇到憑證警告不要硬闖。[官方事件說明](https://blog.mozilla.org/security/2026/10/20/protecting-firefox-users-following-the-compromise-of-emudhra-intermediate-certificates/)

## 我有安裝 AI 工具

**只在 ChatGPT、Gemini、Claude 網站聊天，不代表你裝了受影響的本機 AI 元件。**

如果是桌面 App、外掛或整合多家 AI 的服務，先到它的官方公告或客服確認。對這次 LiteLLM 惡意發行有疑慮時，**先不要啟動可疑工具來查版本或更新**；直接用瀏覽器聯絡官方。不是所有 AI 工具都有使用 LiteLLM，也不用因此把正常工具全部刪掉。

下面這段可直接複製，傳給你使用的工具客服或服務營運者。將「我使用的工具」改成 App 名稱即可，不需要填版本號：

```text
我使用的工具：請改成你的 App／服務名稱

我沒有資訊背景，想確認 2026/10/21 的兩起事件是否影響這個工具：
1. Node.js 安全更新：請確認我真正使用的 App 及內附元件是否已修補，而不是只更新電腦上另外一份 Node。
2. LiteLLM 惡意發行：請從安裝／發布紀錄確認是否使用受污染的發行物；不要為了查版本先啟動可能受污染的環境。

若受影響，請提供官方處理方式、我需要按哪些按鈕、是否要關程式或重啟，以及處理後如何確認真的生效。
若曾執行受污染的 LiteLLM，請同時說明隔離、乾淨重建及可能外洩的登入權限／金鑰要怎麼處理；不要只叫我按更新。
若目前還無法確認，請明說哪些尚未確認。

官方來源：
https://nodejs.org/en/blog/vulnerability/october-2026-security-releases
https://docs.litellm.ai/blog/security-incident-oct-21-2026
```

一般 App 經官方確認可用更新修補後，沿用它的「檢查更新」或原商店更新，重啟後確認能正常使用。**客服回覆「已收到」或 App 顯示「最新版」，都不能單獨證明這次事件已處理。** 未收到明確確認時，記為「待確認」。

## 我有自己的網站

你有自己的 WordPress、部落格、商店或自架服務時，請向主機商或網站維護者確認 PHP2Shell。**只是逛別人的網站，不需要為此安裝 PHP。**

打開原主機商的客服，把下面這段貼過去，補上自己的網站網址即可。請用私人客服管道，不要把後台密碼或網站資料貼到公開留言。

```text
我的網站：請改成你的網站網址

請幫我確認網站主機是否已修補 PHP 官方 2026/10/21 公告的兩個嚴重漏洞（PHP2Shell）。
請檢查網站實際使用的 PHP，而不是只更新 WordPress 或外掛。
如果需要更新，請先確認備份與相容性，告訴我會不會暫停服務、是否有額外費用，等我同意再進行。
處理後請確認網站、登入及主要功能正常，並提供安全修補已生效的確認；若採用回補修正，也請說明。

PHP 官方公告：
https://www.php.net/archive/2026.php#2026-10-21-5
```

**送出客服詢問，只代表已請人檢查。** 要等對方確認修補實際生效、你也確認網站正常，才算這項完成。

## 我不知道自己用到哪些

先完成你平常上網用的瀏覽器更新。只有逛網站、沒有安裝 AI 工具，也沒有自己的網站，就不必為了這份指南另外安裝 Node.js、LiteLLM 或 PHP。

不確定某個 App 是否用到這些元件，就把上方詢問文字交給該 App 官方客服；不要自己猜，也不用先購買或註冊 AI。

做完可記成三種結果：**已更新並確認能用／不適用（已確認沒有使用）／待確認或未完成**。不要把沒有檢查的項目當成安全。

本次四起事件與官方來源見[白話事件說明](PERSONAL-ALERTS.zh-TW.md)。核對日期：**2026/10/23**；之後使用仍應查看當下官方資訊。這不是入侵檢測或整台裝置安全保證。

卡住可到 [GitHub 回報](https://github.com/leavemagic-cyber/ai-security-checkup/issues)，寫「哪種裝置、哪個 App、卡在哪一步」，不要貼密碼、金鑰、驗證碼或私人資料。有幫助請幫 [Repo](https://github.com/leavemagic-cyber/ai-security-checkup) 按 ⭐、分享給需要的親友；不用先按星才能使用。
